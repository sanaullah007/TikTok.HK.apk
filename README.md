# TikTok.HK
Android prototype of a short-form vertical video app.

## Features
- Import videos from your Android device using the system picker.
- Swipe up/down to browse imported videos.
- Like, comment and share videos.
- Local profile and import count.

This is an **offline prototype**. It does not create accounts, upload content to the internet, offer live streams or synchronize across devices. Its name and interface are independently implemented; it is not affiliated with TikTok.

## Build an APK with GitHub Actions
Open **Actions → Build TikTok.HK APK → Run workflow**, or push a commit to main. When the build succeeds, download **TikTok.HK-debug-apk** from the Artifacts section of the workflow run. Unzip the artifact to obtain app-debug.apk.

Requires Android API 24+.
